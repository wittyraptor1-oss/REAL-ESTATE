# ICON architectural experience

A Next.js / React / TypeScript cinematic commercial property presentation using the supplied 10-second architectural film. GSAP, ScrollTrigger, Lenis and Three.js power the navigation, scroll film, horizontal workspaces, and interactive studies.

## Run

`npm install` then `npm run dev`. Preview: http://127.0.0.1:5173

`npm run build` generates a static export in `out/`.

## Implemented

Black façade-fin intro, hero film controls, cinematic film navigation, full-screen navigation with image previews, 121-frame WebP canvas sequence that reverses with scrolling, draggable Three.js tower with selectable zones and camera easing, scroll-exploded sculpture study, horizontal workspace sequence, retail reveal, terrace parallax, accessible architectural hotspot sheets, magnetic buttons, desktop cursor, swipe/keyboard/fullscreen gallery, interactive floor study, abstract map animation, and a four-step validated downloadable enquiry. Reduced-motion and responsive fallbacks are included.

## Project information required

ICON is provisional branding. The 3D geometry, sculpture and 32-level selector are conceptual studies based on the film, not approved architectural models. Floor plans are clearly marked illustrative. Areas, availability, address and travel times are unconfirmed. No location or leasing facts are invented. The enquiry downloads locally and is explicitly not sent; provide a contact email or CRM endpoint to enable delivery. No contact data is persisted.

The supplied film is the sole visual source, including its existing watermark. Dedicated interior imagery, a CAD/GLB model, approved floor drawings and transition-specific films would improve architectural accuracy and seamless match cuts. Performance depends on the device; 60 FPS is a target, not a measured guarantee.
